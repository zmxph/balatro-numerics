## 方法与复现

1. 基准曲线：复用项目的整数计数组合动态规划，计算直接抓 0–30 张牌时的各牌型包含概率。
2. 精确弃牌：对子、对子族、同花分别按剩余点数副本和花色计数压缩状态，枚举所有合法弃法与补牌计数；动态规划最大化剩余全部弃牌机会的最终成功率。
3. 顺子类：容斥计算每次弃法的直接补牌成功率；比较不同前瞻长度与只优化下一次的策略。初步比较和最终评估使用不同种子；最后一轮补牌被解析积分掉，减少方差。策略详情、每项样本数、种子和前瞻参数保存在 results.json。
4. 精确递推与独立实体牌枚举对照，覆盖两轮弃牌及弃牌不放回。

执行顺序：baselines.py → 编译 DiscardAnalysis.csproj → pair 4 / flush 4 / rank 0..3 4 → simulate straight 或 straight_flush 的 pilot、pilot_extra、final → validate → export_results.py。完整入口及参数见源码。

本计算未修改游戏 Mod 或其中原有的 1.5m 近似。
